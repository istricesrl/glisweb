Panoramica delle integrazioni di Facebook con il framework.

introduzione
============

integrazione pixel di Facebook
==============================

[...] inserimento del codice del pixel nel file config.json:
```json
"facebook": {
    "profiles": {
        "PROD": {
            "pixel": {
                "id": "<CODICE-PIXEL-FACEBOOK>"
            }
        }
    }
}
```
[...] esempio di codice del pixel:
```html
<script>
    !function(f,b,e,v,n,t,s)
    {if(f.fbq)return;n=f.fbq=function(){n.callMethod?
    n.callMethod.apply(n,arguments):n.queue.push(arguments)};
    if(!f._fbq)f._fbq=n;n.push=n;n.loaded=!0;n.version='2.0';
    n.queue=[];t=b.createElement(e);t.async=!0;
    t.src=v;s=b.getElementsByTagName(e)[0];
    s.parentNode.insertBefore(t,s)}(window, document,'script',
    'https://connect.facebook.net/en_US/fbevents.js');
    fbq('init', '<CODICE-PIXEL-FACEBOOK>');
    fbq('track', 'PageView');
</script>
<noscript>
    <img height="1" width="1" style="display:none" src="https://www.facebook.com/tr?id=<CODICE-PIXEL-FACEBOOK>&ev=PageView&noscript=1"/>
</noscript>
```
integrazione con Facebook Messenger
===================================
Il framework non integra più la chat di Messenger: Meta ha dismesso il Chat Plugin nel maggio 2024, e la chiave
`facebook.profiles.<ambiente>.messenger` non è letta da nessun file. Chi vuole un contatto via Messenger può mettere
nel template un normale link `https://m.me/<nome-pagina>`.
