Dettagli delle tabelle del database del framework che iniziano con la lettera O.

le tabelle del database di supporto OA - OZ
===========================================

orari
-----
Questa tabella *gestita* contiene fasce orarie per giorno della settimana, legate a una tipologia di contratto e a una
periodicità. Nessun codice del framework oggi la legge o la scrive: le gestioni degli orari dei moduli
`0600.contratti` e `1000.produzione` lavorano sulla tabella *orari_contratti*, qui sotto.

colonna                         | descrizione
--------------------------------|---------------------------------------------------------------------------------------
orari.id                        | l'ID della fascia oraria
orari.nome                      | il nome della fascia oraria
orari.id_tipologia_contratti    | l'ID della tipologia di contratto
orari.id_periodicita            | l'ID della periodicità
orari.id_giorno                 | l'ID del giorno della settimana, dalla tabella *giorni*
orari.ora_inizio                | l'ora di inizio
orari.ora_fine                  | l'ora di fine
orari.note                      | note sulla fascia oraria
orari.id_account_inserimento    | l'ID dell'account che ha inserito la riga
orari.timestamp_inserimento     | la timestamp dell'inserimento della riga
orari.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
orari.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
orari_ibfk_01                     | id_tipologia_contratti        | tipologie_contratti.id        | ON DELETE CASCADE ON UPDATE CASCADE
orari_ibfk_02                     | id_periodicita                | periodicita.id                | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_03_nofollow            | id_giorno                     | giorni.id                     | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_98_nofollow            | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_99_nofollow            | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

La vista *orari_view* relativa alla tabella *orari* presenta le seguenti colonne:

colonna                                 | descrizione
----------------------------------------|---------------------------------------------------------------------------------------
orari_view.id                           | -
orari_view.nome                         | -
orari_view.id_tipologia_contratti       | -
orari_view.id_periodicita               | -
orari_view.id_giorno                    | -
orari_view.ora_inizio                   | -
orari_view.ora_fine                     | -
orari_view.__label__                    | il nome della fascia oraria

orari_contratti
---------------
Questa tabella *gestita* contiene i turni di un contratto: per turno e giorno della settimana le fasce di lavoro
( *se_lavoro* ) e di disponibilità ( *se_disponibile* ), ciascuna legata a un costo del contratto ( *costi_contratti* ).
La usano le schede orari e disponibilità e i task di duplicazione e cancellazione del modulo `0600.contratti`, e il
calcolo delle ore di `1000.produzione`; la scheda del contratto la riceve come sottotabella, perché la chiave verso
*contratti* si segue. Era nello schema del 2021 e non nei file di base: è tornata il 2026-09-30, portata a bigint
( _202609300900.colonne.tabelle.viste.sql per i deploy esistenti ).

colonna                            | descrizione
-----------------------------------|---------------------------------------------------------------------------------------
orari_contratti.id                 | l'ID della fascia
orari_contratti.id_contratto       | l'ID del contratto
orari_contratti.turno              | il numero del turno
orari_contratti.id_giorno          | l'ID del giorno della settimana, dalla tabella *giorni*
orari_contratti.ora_inizio         | l'ora di inizio
orari_contratti.ora_fine           | l'ora di fine
orari_contratti.id_costo           | l'ID del costo del contratto, dalla tabella *costi_contratti*
orari_contratti.se_lavoro          | se la fascia è di lavoro
orari_contratti.se_disponibile     | se la fascia è di disponibilità

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
orari_contratti_ibfk_01           | id_contratto                  | contratti.id                  | ON DELETE CASCADE ON UPDATE CASCADE
orari_contratti_ibfk_02_nofollow  | id_costo                      | costi_contratti.id            | ON DELETE CASCADE ON UPDATE CASCADE

La vista *orari_contratti_view* relativa alla tabella *orari_contratti* presenta le seguenti colonne:

colonna                                 | descrizione
----------------------------------------|---------------------------------------------------------------------------------------
orari_contratti_view.id                 | -
orari_contratti_view.id_contratto       | -
orari_contratti_view.turno              | -
orari_contratti_view.id_giorno          | -
orari_contratti_view.ora_inizio         | -
orari_contratti_view.ora_fine           | -
orari_contratti_view.id_costo           | -
orari_contratti_view.se_lavoro          | -
orari_contratti_view.se_disponibile     | -
orari_contratti_view.__label__          | turno, giorno e fascia oraria

organizzazioni
--------------
Questa tabella *gestita* mette in relazione ad albero i ruoli ricoperti dalle entità anagrafiche specificandone i rapporti e le organizzazioni.

colonna                                             | descrizione
----------------------------------------------------|---------------------------------------------------------------------------------------
organizzazioni.id                                   | l'ID del nodo nell'albero dell'organizzazione
organizzazioni.id_genitore                          | l'ID del nodo genitore nell'albero dell'organizzazione
organizzazioni.ordine                               | campo di ordinamento
organizzazioni.id_anagrafica                        | l'ID dell'anagrafica collegata al nodo
organizzazioni.id_ruolo                             | l'ID del ruolo ricoperto dall'anagrafica nel nodo
organizzazioni.nome                                 | nome del nodo dell'organizzazione
organizzazioni.note                                 | note sul nodo dell'organizzazione
organizzazioni.id_account_inserimento               | l'ID dell'account che ha inserito la riga
organizzazioni.timestamp_inserimento                | la timestamp dell'inserimento della riga
organizzazioni.id_account_aggiornamento             | l'ID dell'ultimo account che ha modificato la riga
organizzazioni.timestamp_aggiornamento              | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

chiave                                      | campo                         | tabella e campo collegati     | comportamento
--------------------------------------------|-------------------------------|-------------------------------|----------------------
organizzazioni_ibfk_01_nofollow             | id_genitore                   | organizzazioni.id             | ON DELETE NO ACTION ON UPDATE CASCADE
organizzazioni_ibfk_02                      | id_anagrafica                 | anagrafica.id                 | ON DELETE SET NULL ON UPDATE SET NULL
organizzazioni_ibfk_03_nofollow             | id_ruolo                      | ruoli_anagrafica.id           | ON DELETE NO ACTION ON UPDATE CASCADE
organizzazioni_ibfk_98_nofollow             | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
organizzazioni_ibfk_99_nofollow             | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
