le tabelle del database di supporto OA - OZ
===========================================

orari
-----
Questa tabella *gestita* secondaria contiene le fasce orarie in cui vale una tipologia di contratto, tipicamente un
abbonamento: ogni riga è un giorno della settimana con l'ora di inizio e l'ora di fine. Le righe appartengono alla
tipologia: la chiave verso *tipologie_contratti* si segue, la scheda della tipologia le riceve come sottotabella e
le cancella con lei. È per le ore quello che *periodi* è per le date, e il nome resta generico perché la tabella può
essere associata anche ad altri oggetti, con una colonna per ciascuno; *id_periodicita* oggi vale sempre
settimanale. Nel framework latest c'è solo il permesso; la scrivono e la leggono i moduli legacy `0640.abbonamenti`
( la scheda della tipologia ) e `0920.corsi` ( la verifica che una lezione cada nelle fasce dell'abbonamento ). Le
gestioni degli orari dei moduli `0600.contratti` e `1000.produzione` lavorano invece sulla tabella *orari_contratti*,
qui sotto.

colonna                         | descrizione
--------------------------------|---------------------------------------------------------------------------------------
orari.id                        | l'ID della fascia oraria
orari.nome                      | il nome della fascia oraria
orari.id_tipologia_contratti    | l'ID della tipologia di contratto
orari.id_periodicita            | l'ID della periodicità
orari.id_giorno                 | l'ID del giorno della settimana, dalla tabella *giorni*
orari.ora_inizio                | l'ora di inizio
orari.ora_fine                  | l'ora di fine
orari.note                      | note sulla fascia oraria
orari.id_account_inserimento    | l'ID dell'account che ha inserito la riga
orari.timestamp_inserimento     | la timestamp dell'inserimento della riga
orari.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
orari.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

----------------------------------|-------------------------------|-------------------------------|----------------------

orari_ibfk_02                     | id_periodicita                | periodicita.id                | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_03_nofollow            | id_giorno                     | giorni.id                     | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_98_nofollow            | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
orari_ibfk_99_nofollow            | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

orari_contratti
---------------
Questa tabella *gestita* contiene i turni settimanali di un contratto di lavoro: per turno e giorno della settimana le
fasce di lavoro ( *se_lavoro* ), ciascuna legata a un costo orario del contratto ( *costi_contratti* ), e quelle di
disponibilità ( *se_disponibile* ), in cui la persona può essere chiamata. Insieme a *costi_contratti* definisce il
perimetro dei contratti di lavoro, e passerà al modulo risorse umane di latest. Il turno numera le settimane di una
rotazione; un giorno vuoto vale per tutti i giorni. Un costo usato da qualche fascia non si può cancellare.
La usano le schede orari e disponibilità e i task di duplicazione e cancellazione del modulo `0600.contratti`, il
calcolo delle ore di `1000.produzione` e `8100.cartellini` e lo schema dei turni di `0200.attivita`; la scheda del
contratto la riceve come sottotabella, perché la chiave verso *contratti* si segue. Era nello schema del 2021 e non
nei file di base: è tornata il 2026-09-30, portata a bigint ( _202609300900.colonne.tabelle.viste.sql per i deploy
esistenti ).

colonna                            | descrizione
-----------------------------------|---------------------------------------------------------------------------------------
orari_contratti.id                 | l'ID della fascia
orari_contratti.id_contratto       | l'ID del contratto
orari_contratti.turno              | il numero del turno nella rotazione
orari_contratti.id_giorno          | l'ID del giorno della settimana, dalla tabella *giorni* ( vuoto = tutti i giorni )
orari_contratti.ora_inizio         | l'ora di inizio
orari_contratti.ora_fine           | l'ora di fine
orari_contratti.id_costo           | l'ID del costo del contratto, dalla tabella *costi_contratti*
orari_contratti.se_lavoro          | se la fascia è di lavoro
orari_contratti.se_disponibile     | se la fascia è di disponibilità

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
orari_contratti_ibfk_01           | id_contratto                  | contratti.id                  | ON DELETE CASCADE ON UPDATE CASCADE
orari_contratti_ibfk_02_nofollow  | id_costo                      | costi_contratti.id            | ON DELETE NO ACTION ON UPDATE CASCADE
