===========================================

badge
-----
Questa tabella *gestita* contiene i badge, cioè i dispositivi di identificazione — tesserini, chiavette RFID e simili —
identificati da un codice, unico per tipologia, o da un RFID, unico in assoluto. Si gestisce col modulo dei badge e
serve per i controlli di accesso e per gli scenari di automazione e domotica. Un'anagrafica può essere titolare di più
badge e a un contratto possono essere associati più badge: per questo il legame sta qui, nelle colonne *id_anagrafica*
e *id_contratto*, come per le tabelle dei media; se il titolare o il contratto vengono cancellati il badge resta, non
assegnato.

colonna                         | descrizione
--------------------------------|---------------------------------------------------------------------------------------
badge.id                        | l'ID del badge
badge.id_tipologia              | l'ID della tipologia del badge, dalla tabella *tipologie_badge*
badge.codice                    | il codice del badge, unico per tipologia
badge.nome                      | il nome del badge
badge.id_anagrafica             | l'ID dell'anagrafica titolare del badge
badge.id_contratto              | l'ID del contratto a cui è associato il badge
badge.rfid                      | il codice RFID del badge, unico
badge.note                      | note sul badge
badge.id_account_inserimento    | l'ID dell'account che ha inserito la riga
badge.timestamp_inserimento     | la timestamp dell'inserimento della riga
badge.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
badge.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
badge_ibfk_01_nofollow            | id_tipologia                  | tipologie_badge.id            | ON DELETE NO ACTION ON UPDATE CASCADE
badge_ibfk_02                     | id_anagrafica                 | anagrafica.id                 | ON DELETE SET NULL ON UPDATE SET NULL
badge_ibfk_03                     | id_contratto                  | contratti.id                  | ON DELETE SET NULL ON UPDATE SET NULL
badge_ibfk_98_nofollow            | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
badge_ibfk_99_nofollow            | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

banner
------
Questa tabella *gestita* contiene i banner, pubblicitari o informativi, da mostrare sui siti e sulle app mobile. Si
gestisce col modulo dei banner, che ne cura la generazione, la rotazione, la collocazione negli spazi e il tracciamento
delle visualizzazioni e dei click in *attivita*, con le tipologie *banner* → *visualizzazione* e *click*. L'immagine e il testo stanno nelle tabelle dei media, collegate
con *id_banner*; dove e quando il banner appare sta in *pubblicazioni*, dove ogni riga è una collocazione col sito o
l'app, lo spazio, l'ordine e il periodo di validità. Un banner può portare i click a un contratto di affiliazione.

colonna                          | descrizione
---------------------------------|---------------------------------------------------------------------------------------
banner.id                        | l'ID del banner
banner.id_tipologia              | l'ID della tipologia del banner, dalla tabella *tipologie_banner*
banner.ordine                    | campo di ordinamento
banner.nome                      | il nome del banner
banner.id_inserzionista          | l'ID dell'anagrafica inserzionista
banner.id_affiliazione           | l'ID del contratto di affiliazione a cui vengono attribuiti i click, come *account.id_affiliazione*
banner.larghezza                 | la larghezza del banner in pixel
banner.altezza                   | l'altezza del banner in pixel
banner.note                      | note sul banner
banner.timestamp_inserimento     | la timestamp dell'inserimento della riga
banner.id_account_inserimento    | l'ID dell'account che ha inserito la riga
banner.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga
banner.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
banner_ibfk_01_nofollow           | id_tipologia                  | tipologie_banner.id           | ON DELETE NO ACTION ON UPDATE CASCADE
banner_ibfk_02_nofollow           | id_inserzionista              | anagrafica.id                 | ON DELETE SET NULL ON UPDATE SET NULL
banner_ibfk_03_nofollow           | id_affiliazione               | contratti.id                  | ON DELETE SET NULL ON UPDATE SET NULL
banner_ibfk_98_nofollow           | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
banner_ibfk_99_nofollow           | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

banner_azioni
-------------
Questa tabella *gestita* registra le azioni sui banner, cioè le visualizzazioni e i click. La scrive l'API del modulo
`3300.banner`: _banner.php a ogni visualizzazione, _click.php a ogni click prima di reindirizzare al link del banner,
ritrovato attraverso *token*. La colonna *id_pagina* non viene valorizzata dal codice di oggi. **In dismissione**: le
visualizzazioni e i click diventano righe di *attivita* ( tipologie *banner* → *visualizzazione* e *click*, colonne
*id_banner* e *id_pubblicazione*, *token* dell'impressione ), e la tabella esce con la sua vista.

colonna                                 | descrizione
----------------------------------------|---------------------------------------------------------------------------------------
banner_azioni.id                        | l'ID dell'azione
banner_azioni.id_pagina                 | l'ID della pagina su cui è avvenuta l'azione
banner_azioni.id_banner                 | l'ID del banner
banner_azioni.azione                    | il tipo di azione: *visualizzazione* o *click*
banner_azioni.timestamp_azione          | la timestamp dell'azione
banner_azioni.token                     | il token della visualizzazione a cui l'azione si riferisce
banner_azioni.id_account_inserimento    | l'ID dell'account che ha inserito la riga
banner_azioni.timestamp_inserimento     | la timestamp dell'inserimento della riga
banner_azioni.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
banner_azioni.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

chiave                            | campo                         | tabella e campo collegati     | comportamento
----------------------------------|-------------------------------|-------------------------------|----------------------
banner_azioni_ibfk_01             | id_banner                     | banner.id                     | ON DELETE SET NULL ON UPDATE SET NULL
banner_azioni_ibfk_02_nofollow    | id_pagina                     | pagine.id                     | ON DELETE SET NULL ON UPDATE SET NULL
banner_azioni_ibfk_98_nofollow    | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
banner_azioni_ibfk_99_nofollow    | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

La vista *banner_azioni_view* relativa alla tabella *banner_azioni* presenta le seguenti colonne:
