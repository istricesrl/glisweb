Descrizione della factory mail del framework.

introduzione
============
La factory mail è la parte del framework che si occupa della creazione e dell'invio delle mail.

code delle mail in uscita e inviate
===================================
Le mail si accodano nella tabella `mail_out` con `queueMail()` o `queueMailFromTemplate()` di
`_src/_lib/_mail.tools.php`; il task `_src/_api/_task/_mail.queue.send.php` ( o la sua copia nel modulo `MA000.mail` )
ne invia una per giro con `sendMail()` e la sposta nell'archivio `mail_sent`, che ha le stesse colonne nello stesso
ordine; i file collegati alla mail ( `file.id_mail_out` ) passano alla mail inviata ( `file.id_mail_sent` ). Una mail
che non parte resta in coda e viene riprovata dopo tante ore quanti sono i tentativi fatti, fino a
`$cf['mail']['tentativi_massimi']` tentativi falliti ( default 10, `_src/_config/_350.mail.php`; 0 toglie il limite ):
lì resta in `mail_out` ferma con il token dedicato `TROPPI_TENTATIVI`, con un errore nel log `mail` e il titolo della
scheda che lo dice, e non la riprendono né il cron né "elabora coda" ( `full=1` ); la fa ripartire, con i tentativi
azzerati, l'invio forzato dalla scheda della mail in uscita. Una mail partita ma non
copiata fra le inviate resta in `mail_out` bloccata dal token dedicato `COPIA_FALLITA`, con un errore critico nel log
`mail`, e va sistemata a mano. Il task marca la riga che sta inviando con il proprio token e l'ora della marcatura
( `timestamp_elaborazione` ), e all'inizio di ogni giro sblocca le righe marcate da più di
`$cf['mail']['minuti_sblocco']` minuti ( default 60, `_src/_config/_350.mail.php` ), rimaste indietro da un giro
morto a metà. Dalla scheda di una mail inviata il task `mail.queue.resend` del modulo `MA000.mail` la rimette in coda
con tentativi e data prevista azzerati, allegati compresi. I dettagli stanno nelle voci dei task in `212.file.api.md`
e nel `READ.md` del modulo.

template per le mail
====================

la funzione queueMailFromTemplate()
-----------------------------------
```php
// accodamento
    queueMailFromTemplate(
        $cf['mysql']['connection'],
        $cf['mail']['tpl']['DEFAULT'],
        array( 'dt' => array( 'chiave' => 'valore' ), 'ct' => $ct ),
        strtotime( '+5 minutes' ),
        array( 'Pinco Pallo' => 'pinco.pallo@domain.bogus' ),
        'it-IT'
    );
```

### come abilito la firma DKIM per la posta inviata dal framework?
Le chiavi DKIM vengono memorizzate in /etc/secret/<nomeDominio>; per utilizzarle è necessario aggiungere un record DKIM al proprio DNS. Lo script
/_src/_sh/_dkim.keygen.sh è pensato per aiutare in questo processo.
