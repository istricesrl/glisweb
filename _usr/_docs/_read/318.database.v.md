le tabelle del database di supporto VA - VZ
===========================================

valutazioni
-----------
Questa tabella *gestita* contiene le valutazioni di un immobile o di una matricola fatte per un'anagrafica, con
superfici, condizione, disponibilità e classe energetica. Si gestisce dalle viste e dalle schede dei moduli
`0800.valutazioni` e `V300.immobiliari`, che hanno anche la scheda delle certificazioni ( *valutazioni_certificazioni*
).

colonna                               | descrizione
--------------------------------------|---------------------------------------------------------------------------------------
valutazioni.id                        | l'ID della valutazione
valutazioni.id_anagrafica             | l'ID dell'anagrafica per cui è fatta la valutazione
valutazioni.id_matricola              | l'ID della matricola valutata
valutazioni.id_immobile               | l'ID dell'immobile valutato
valutazioni.mq_commerciali            | i metri quadri commerciali
valutazioni.mq_calpestabili           | i metri quadri calpestabili
valutazioni.id_condizione             | l'ID della condizione, dalla tabella *condizioni*
valutazioni.id_disponibilita          | l'ID della disponibilità, dalla tabella *disponibilita*
valutazioni.id_classe_energetica      | l'ID della classe energetica, dalla tabella *classi_energetiche*
valutazioni.note                      | note sulla valutazione
valutazioni.timestamp_valutazione     | la timestamp della valutazione
valutazioni.id_account_inserimento    | l'ID dell'account che ha inserito la riga
valutazioni.timestamp_inserimento     | la timestamp dell'inserimento della riga
valutazioni.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
valutazioni.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

----------------------------------|-------------------------------|-------------------------------|----------------------
valutazioni_ibfk_01_nofollow      | id_anagrafica                 | anagrafica.id                 | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_02_nofollow      | id_matricola                  | matricole.id                  | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_03_nofollow      | id_immobile                   | immobili.id                   | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_04_nofollow      | id_condizione                 | condizioni.id                 | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_05_nofollow      | id_disponibilita              | disponibilita.id              | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_06_nofollow      | id_classe_energetica          | classi_energetiche.id         | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_98_nofollow      | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_ibfk_99_nofollow      | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

valutazioni_certificazioni
--------------------------
Questa tabella *gestita* registra le certificazioni collegate a una valutazione ( per esempio l'attestato di
prestazione energetica di un immobile ), con l'ente emittente e le date. Si compila dalla scheda *certificazioni*
delle gestioni valutazioni dei moduli `0800.valutazioni` e `V300.immobiliari` e dalle viste del modulo
`6700.certificazioni`.

colonna                                              | descrizione
-----------------------------------------------------|---------------------------------------------------------------------------------------
valutazioni_certificazioni.id                        | l'ID della certificazione della valutazione
valutazioni_certificazioni.id_valutazione            | l'ID della valutazione
valutazioni_certificazioni.id_certificazione         | l'ID della certificazione, dalla tabella *certificazioni*
valutazioni_certificazioni.id_emittente              | l'ID dell'anagrafica che ha emesso la certificazione
valutazioni_certificazioni.nome                      | il nome della certificazione; la colonna è dichiarata `char(1)`, cioè di un solo carattere
valutazioni_certificazioni.codice                    | il codice o numero del certificato
valutazioni_certificazioni.data_emissione            | la data di emissione
valutazioni_certificazioni.data_scadenza             | la data di scadenza
valutazioni_certificazioni.note                      | note sulla certificazione
valutazioni_certificazioni.id_account_inserimento    | l'ID dell'account che ha inserito la riga
valutazioni_certificazioni.timestamp_inserimento     | la timestamp dell'inserimento della riga
valutazioni_certificazioni.id_account_aggiornamento  | l'ID dell'ultimo account che ha modificato la riga
valutazioni_certificazioni.timestamp_aggiornamento   | la timestamp dell'ultimo aggiornamento della riga

La tabella ha le seguenti chiavi esterne:

chiave                                       | campo                         | tabella e campo collegati     | comportamento
---------------------------------------------|-------------------------------|-------------------------------|----------------------
valutazioni_certificazioni_ibfk_01           | id_valutazione                | valutazioni.id                | ON DELETE CASCADE ON UPDATE CASCADE
valutazioni_certificazioni_ibfk_02_nofollow  | id_certificazione             | certificazioni.id             | ON DELETE CASCADE ON UPDATE CASCADE
valutazioni_certificazioni_ibfk_03_nofollow  | id_emittente                  | anagrafica.id                 | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_certificazioni_ibfk_98_nofollow  | id_account_inserimento        | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL
valutazioni_certificazioni_ibfk_99_nofollow  | id_account_aggiornamento      | account.id                    | ON DELETE SET NULL ON UPDATE SET NULL

veicoli
-------
Questa tabella *gestita* contiene i veicoli, con la loro tipologia, la targa, il modello e il costruttore. La gestisce il
modulo `VE000.veicoli`.

colonna                              | descrizione
-------------------------------------|---------------------------------------------------------------------------------------
veicoli.id                           | l'ID del veicolo
veicoli.id_tipologia                 | l'ID della tipologia del veicolo
veicoli.targa                        | la targa del veicolo
veicoli.modello                      | il modello del veicolo
veicoli.id_costruttore               | l'ID dell'anagrafica del costruttore del veicolo
veicoli.nome                         | il nome del veicolo
veicoli.descrizione                  | la descrizione del veicolo
veicoli.data_archiviazione           | data in cui viene archiviato il veicolo
veicoli.note_archiviazione           | note aggiuntive sull'archiviazione del veicolo
veicoli.id_account_inserimento       | l'ID dell'account che ha inserito la riga
veicoli.timestamp_inserimento        | la timestamp dell'inserimento della riga
veicoli.id_account_aggiornamento     | l'ID dell'ultimo account che ha modificato la riga
veicoli.timestamp_aggiornamento      | la timestamp dell'ultimo aggiornamento della riga

La tabella ha chiave primaria con AUTO_INCREMENT su *id* e gli indici su *id_tipologia*, *id_costruttore*, *targa*,
*nome*, *data_archiviazione* e sugli account, ma nessun vincolo di chiave esterna.

La vista *veicoli_view* relativa alla tabella *veicoli* presenta le seguenti colonne:

colonna                                   | descrizione
------------------------------------------|---------------------------------------------------------------------------------------
veicoli_view.id                           | -
veicoli_view.id_tipologia                 | -
veicoli_view.tipologia                    | il percorso della tipologia del veicolo
veicoli_view.id_costruttore               | -
veicoli_view.produttore                   | la denominazione, o cognome e nome, del costruttore
veicoli_view.modello                      | -
veicoli_view.targa                        | -
veicoli_view.data_archiviazione           | -
veicoli_view.id_account_inserimento       | -
veicoli_view.id_account_aggiornamento     | -
veicoli_view.__label__                    | etichetta descrittiva del veicolo: costruttore, nome, modello e targa separati da trattino
