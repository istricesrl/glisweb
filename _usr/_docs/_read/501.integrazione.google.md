Panoramica delle integrazioni di Google con il framework.

introduzione
============

Google Tag Manager
------------------
Il contenitore di Tag Manager si configura nel profilo con `property` ed eventualmente il flag `anonymous`
( vedi `/_src/_config/_115.google.php` ). Gli snippet `_gtm.head` e `_gtm.noscript` ( Twig e HTML ) lo caricano
se il profilo è anonimo, oppure se l'utente ha dato il consenso al cookie `GoogleTagManager`, che il progetto deve
dichiarare in `privacy.cookie.terzi.analitici` ( esempio in [160.privacy.md](160.privacy.md) ): il consenso si
legge in `privacy.cookie.terzi.analitici.GoogleTagManager.consenso`, lo stesso percorso a tre livelli in cui lo
scrivono l'overlay dei cookie e la POST `__cookie__`.

integrazione con Google Analytics
=================================

[...] configurazione del profilo Analytics nel file config.json ( con `anonymous` a `true` lo script parte sempre
e anonimizza l'IP; altrimenti parte solo col consenso al cookie `GoogleAnalytics` dichiarato in
`privacy.cookie.terzi.analitici`, letto in `privacy.cookie.terzi.analitici.GoogleAnalytics.consenso` ):
```json
"google": {
    "profiles": {
        "PROD": {
            "analytics": {
                "ua": "<CODICE-GOOGLE-ANALYTICS>",
                "anonymous": true
            }
        }
    }
}
```

### come configuro Google Analytics per misurare le visite al mio sito?
Devi compilare l'apposita sezione del file di configurazione; supponendo che tu abbia usato YAML, avrai qualcosa di simile:

```
google:
  profiles:
    DEV:
      analytics:
        ua: "IL-TUO-CODICE-ANALYTICS"
        anonymous: true
```
