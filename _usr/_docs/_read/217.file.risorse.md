# i file di /_src/_css, /_src/_js e /_src/_img

> `READ.md`, nella radice del framework. I percorsi sono stati verificati uno per uno contro

Fogli di stile, script e immagini dello standard. Sono le risorse che i template caricano senza
doverle dichiarare, e vanno distinte da quelle che ogni tema si porta dietro.

### /_src/_css/_back2top.css
In questo file viene definito lo stile CSS per il tasto "torna su".

### /_src/_css/_main.css
Questo file contiene gli stili di base validi per tutti i template.

### /_src/_css/_selectbox.css
Questo file contiene gli stili per la tendina intelligente (combobox).

### /_src/_css/_terminale.css
Questo file contiene gli stili per il terminale (va verificato che siano ancora necessari perché risalgono alla versione precedente del framework).

Le librerie Javascript sono descritte qui una per una; **come si caricano, come si estendono e cosa
leggono nel markup** è invece il capitolo `156.javascript.md`.

### /_src/_js/_main.js
Questa libreria Javascript contiene le funzioni di utilità generale del framework — stringhe, date, invio e validazione dei form — nonché le operazioni
da eseguire al caricamento del DOM, che sono il punto in cui il framework aggancia al markup quasi tutti i suoi comportamenti: avviso dei cookie,
finestre modali, pannelli a scomparsa, ritorno in cima alla pagina, barra di navigazione, megamenu e accensione dei tooltip di Bootstrap 5.

### /_src/_js/_lib/_bootstrap-wysiwyg.js
Questa libreria Javascript accende l'editor bootstrap-wysiwyg sugli elementi con la classe corrispondente. Nessun template e nessuna pagina la
dichiarano: va considerata un'alternativa non in uso.

### /_src/_js/_lib/_ckeditor.js
Questa libreria Javascript accende l'editor di testo ricco CKEditor sugli elementi con classe `ckEditor`, leggendone l'altezza dall'attributo `height`.
È l'unica libreria che si porta dietro dei file di terze parti dentro il framework, in `/_src/_js/_lib/_ext/`.

### /_src/_js/_lib/_CLEditor.js
Questa libreria Javascript accende l'editor CLEditor sugli elementi con la classe corrispondente. Nessun template e nessuna pagina la dichiarano: va
considerata un'alternativa non in uso.

### /_src/_js/_lib/_codemirror.js
Questa libreria Javascript accende l'editor di codice CodeMirror sulle aree di testo con classe `CodeMirror`, e definisce il modo di evidenziazione
`twig-htmlmixed`, che sovrappone la sintassi Twig a quella dell'HTML.

### /_src/_js/_lib/_crosshow.js
Questa libreria Javascript contiene `crossFade()` e `crossShow()`, le due funzioni con cui i form a linguette scambiano i pannelli visibili. Vengono
richiamate dal markup dei template, non si accendono da sole.

### /_src/_js/_lib/_form.js
Questa libreria Javascript contiene la validazione dei form lato client: i controlli su indirizzi di posta, numeri di telefono e campi obbligatori, e i
tre attributi che esprimono vincoli fra campi diversi — `also-required`, `required-equals` e `required-alternative`. Nessuno dei tre ha una controparte
lato server.

### /_src/_js/_lib/_paypal.js
Questa libreria Javascript implementa il pagamento con PayPal, sia con i pulsanti sia con i campi carta soggetti a verifica 3-D Secure, dialogando con
gli endpoint del modulo ecommerce.

### /_src/_js/_lib/_quill.js
Questa libreria Javascript accende l'editor Quill. È quasi interamente commentata e va considerata un'alternativa non in uso.

### /_src/_js/_lib/_rest.js
Questa libreria Javascript contiene funzioni che semplificano l'interazione con gli endpoint REST: `getws()` e `postws()` per le chiamate diciamo
normali, `metroWs()` e `metroLoopWs()` per quelle fatte partire da un riquadro dell'interfaccia, che ne mostrano l'avanzamento nell'icona. È la libreria
da dichiarare per prima, perché le sue funzioni sono usate da tutte le altre.

### /_src/_js/_lib/_selectbox.js
Questa libreria Javascript implementa una semplice combobox per il framework: trasforma un campo nascosto con classe `selectbox` in una tendina che
interroga le API mentre si scrive, con i vincoli di ricerca dichiarati negli attributi `restrict-*`.

### /_src/_js/_lib/_tinyMCE.js
Questa libreria Javascript accende l'editor TinyMCE sugli elementi con la classe corrispondente. Nessun template e nessuna pagina la dichiarano: va
considerata un'alternativa non in uso.

### /_src/_js/_lib/_toastEditor.js
Questa libreria Javascript accende l'editor Toast UI sugli elementi con la classe corrispondente. Nessun template e nessuna pagina la dichiarano: va
considerata un'alternativa non in uso.

### /_src/_js/_lib/_uploader.js
Questa libreria Javascript implementa un semplice file uploader per il framework: carica il file a blocchi verso `api/upload` passando i metadati negli
header, e scrive il percorso restituito nel campo indicato dall'attributo `uploader-field`.

### /_src/_img/_favicon.ico
Questa è la favicon di default del framework. Riguardo alla favicon, si devono tenere presenti diversi file primo fra tutti il file /.htaccess che
effettua il routing da /favicon.ico a /_src/_img/_favicon.ico a meno che /favicon.ico non esista. Questo è un modo deprecato di customizzare la favicon
dato che è disponibile un meccanismo molto più avanzato che consente di fornire al browser formati diversi di favicon.
